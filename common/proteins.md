# 蛋白质与修复材料设计

状态：六类蛋白质已注册，包含组成、初始处理速度、物理参数与化学能；修复逻辑尚未实现。化学处理遵循 [通用化学系统设计](chemistry.md)。

## 材料定义

六类蛋白质均为化合物，按不同的稳定 ID 保存。下列组成单元是游戏中的守恒计算约定，不是真实蛋白质分子式。第一版只使用 C、H、O、N，不包含硫。

| 材料 | 稳定 ID | 代表组成单元 | 初始处理速度 |
| --- | --- | --- | --- |
| 结构蛋白 | `structural_protein` | `C12H19N3O4` | 30% |
| 膜蛋白 | `membrane_protein` | `C15H25N3O4` | 40% |
| 收缩蛋白 | `contractile_protein` | `C12H20N4O5` | 35% |
| 感知蛋白 | `sensory_protein` | `C14H21N5O5` | 20% |
| 角质蛋白 | `keratin_protein` | `C10H16N2O3` | 10% |
| 酶蛋白 | `enzyme_protein` | `C10H16N4O5` | 50% |

膜蛋白碳比例较高，感知蛋白和酶蛋白氮比例较高。角质蛋白暂省略真实角蛋白中的硫。酶蛋白只作为反应结构的修复材料，不改变万能酶规则，也不限制某种反应必须具有某种酶。

组成以结构化整数原子数保存，质量比例按 C=12、H=1、O=16、N=14 计算。比例中的 N 指氮原子数，不是 `nitrogen` 氮气分子数；从氮气参与反应时需按 N2 换算。

| 材料 | C:H:O:N 原子数比 | 组成单元相对质量 | C/H/O/N 质量百分比（约） |
| --- | --- | --- | --- |
| 结构蛋白 | 12:19:4:3 | 269 | 53.5 / 7.1 / 23.8 / 15.6 |
| 膜蛋白 | 15:25:4:3 | 311 | 57.9 / 8.0 / 20.6 / 13.5 |
| 收缩蛋白 | 12:20:5:4 | 300 | 48.0 / 6.7 / 26.7 / 18.7 |
| 感知蛋白 | 14:21:5:5 | 339 | 49.6 / 6.2 / 23.6 / 20.6 |
| 角质蛋白 | 10:16:3:2 | 212 | 56.6 / 7.5 / 22.6 / 13.2 |
| 酶蛋白 | 10:16:5:4 | 272 | 44.1 / 5.9 / 29.4 / 20.6 |

百分比仅供展示，舍入后可能不等于 100%；执行时使用整数组成，不能使用展示百分比扣除库存。不额外附加水解或脱水步骤，也不强制先转成氨基酸。

## 组件材料需求

组件通过 `repair_materials` 声明修复材料，未来以恢复每点耐久所需的 mg 表示。多种材料构成共同需求，不是可任选一种替代。

| 组件 | 修复材料 |
| --- | --- |
| 小型躯体 I | 结构蛋白 |
| 喷射器官 I | 结构蛋白 + 收缩蛋白 |
| 吸收器官 I | 结构蛋白 + 膜蛋白 |
| 皮肤 I | 角质蛋白 |
| 感光器官 I | 膜蛋白 + 感知蛋白 |
| 反应结构 I | 结构蛋白 + 酶蛋白 |
| 传感器组 I | 结构蛋白 + 感知蛋白 |
| 气室结构 I | 结构蛋白 + 膜蛋白 |

修复同时消耗指定材料和能量；具体材料数量、能耗、修复吞吐量及损坏组件恢复规则留待修复系统设计。现有修复权重用于分配修复，不替代材料需求。

初始处理速度只用于蛋白质参与通用化学反应，不直接乘到修复速度上。材料 ID 决定修复兼容性，组成决定化学原料需求，两者各自保留。

## 注册参数与后续边界

六类蛋白质暂统一使用固态面密度 1.35（沿用注册表单位）、化学能 -10.0 mJ/mg（已应用统一的 2 倍参考能量倍率），作为可调整的游戏参数，不代表真实测量值或营养供能量。不模拟稳定液态和气态，熔点、沸点留空。组成按上表保存为结构化原子数，可参与通用守恒与理论能量差计算；不绑定固定合成配方。

氨基酸可另以 `amino_acid`、代表组成 `C2H5NO2`、初始处理速度 80% 作为通用原料候选，尚未注册；它不是合成或修复这些蛋白质的强制中间产物。
